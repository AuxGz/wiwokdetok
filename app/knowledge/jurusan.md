# Program Keahlian (Jurusan) SMK Telkom Purwokerto

SMK Telkom Purwokerto memiliki 4 program keahlian unggulan berstandar industri dengan fasilitas laboratorium modern dan sertifikasi kompetensi resmi:
1. Rekayasa Perangkat Lunak (RPL)
2. Pengembangan Game (PG)
3. Teknik Komputer & Jaringan (TKJ)
4. Teknik Jaringan Akses Telekomunikasi (TJA / TJAT)

## 1. Rekayasa Perangkat Lunak (RPL)
Program keahlian RPL mempelajari pemrograman, basis data, dan rekayasa perangkat lunak aplikasi web maupun mobile dengan alur kerja industri modern.

### Pilar Kompetensi RPL:
- **Software Development**: Membangun aplikasi web dan mobile fungsional dari perancangan arsitektur hingga deployment dan rilis.
- **Database & Back-end**: Merancang skema basis data relasional, REST API, dan integrasi layanan backend (seperti Laravel, Node.js, MySQL).
- **UI/UX & Quality**: Merancang antarmuka pengguna interaktif dan melakukan pengujian jaminan kualitas (QA/testing) aplikasi.

### Peluang Karier RPL:
Software Engineer, Web Developer, Mobile App Developer (Android/iOS), Database Administrator, Quality Assurance (QA) Engineer, System Analyst.

---

## 2. Pengembangan Game (PG)
Program keahlian PG mempelajari perancangan, pembuatan, dan pengembangan video game interaktif untuk berbagai platform (PC, konsol, dan perangkat mobile).

### Pilar Kompetensi PG:
- **Game Programming & Engine**: Membangun logika game, kecerdasan buatan (AI) musuh, fisika, dan mekanik permainan menggunakan game engine standar industri seperti Unity atau Unreal Engine.
- **2D/3D Game Art & Assets**: Merancang dan memproduksi aset visual, mulai dari karakter, lingkungan (environment), objek, hingga animasi dalam format 2D maupun 3D.
- **Game Design & Mechanics**: Merancang alur cerita, aturan gameplay, tingkat kesulitan (level design), serta antarmuka pemain (UI/UX game).

### Peluang Karier PG:
Game Developer, Game Programmer, Game Designer, 2D/3D Artist, Technical Artist, Game QA Tester.

---

## 3. Teknik Komputer & Jaringan (TKJ)
Program keahlian TKJ berfokus pada perakitan keras komputer, instalasi sistem operasi, serta perancangan, administrasi, dan keamanan infrastruktur jaringan komputer.

### Pilar Kompetensi TKJ:
- **Network Infrastructure & Design**: Merancang, membangun, dan mengonfigurasi topologi jaringan (LAN/WAN/WLAN) menggunakan perangkat standar industri seperti router, switch, dan MikroTik.
- **System & Server Administration**: Mengonfigurasi dan memelihara sistem operasi jaringan (Linux/Windows Server) serta pengelolaan layanan server terpusat.
- **Cyber Security & Troubleshooting**: Mengamankan lalu lintas data jaringan dari ancaman siber dan menangani pemecahan masalah (troubleshooting) perangkat keras dan lunak.

### Peluang Karier TKJ:
Network Engineer, Network Administrator, System Administrator, IT Support / Helpdesk, Teknisi Komputer & Jaringan.

---

## 4. Teknik Jaringan Akses Telekomunikasi (TJA / TJAT)
Program keahlian TJA berfokus pada teknologi telekomunikasi broadband, meliputi instalasi jaringan kabel fiber optik (Fiber to the Home / FTTH), sistem transmisi radio, hingga infrastruktur komunikasi seluler dan nirkabel.

### Pilar Kompetensi TJA:
- **Fiber Optic & Broadband Network**: Mempelajari teknik instalasi, penyambungan kabel (splicing), dan pengukuran kualitas redaman jaringan fiber optik untuk layanan internet rumah (FTTH).
- **Wireless & Cellular Technology**: Memahami sistem komunikasi radio, gelombang microwave, dan teknologi seluler termasuk perangkat menara telekomunikasi (Base Transceiver Station / BTS).
- **Telecommunication Infrastructure**: Perancangan, pemeliharaan (maintenance), dan perbaikan (troubleshooting) perangkat akses pelanggan dan sentral telekomunikasi.

### Peluang Karier TJA:
Teknisi Fiber Optik (Splicer), Teknisi Instalasi Telekomunikasi (Installer), Drive Tester Telekomunikasi, Rigger (Teknisi Menara BTS), Network Access Engineer.
